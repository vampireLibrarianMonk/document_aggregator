# TGX-9 Telemetry Gateway Incident — walkthrough

A complete, step-by-step walkthrough of running the TGX-9 sample through the
app, from an empty start to an exported corrected report. The source material
for this walkthrough lives in the repository under
`sample_docs/project/1/` — you can compare your results against it.

This guide is built up as the workflow is completed, one step at a time. Each
step says exactly what to enter/upload and what you should see.

---

## Step 1 — Create the project

Open the app (it starts empty on the **New Project** tab) and create the
project.

- **Project name:**

  ```
  TGX-9 Telemetry Gateway Incident
  ```

- **Description:**

  ```
  Hardware reliability / incident response. Correction of a TGX-9 telemetry
  gateway outage report: the North Ridge relay station dropped inbound sensor
  packets under thermal stress on firmware 4.2.1. Reconciles the field report
  and root-cause notes against a first-attempt report and reviewer corrections.
  ```

Click **Create project**.

**What you should see:** the project is created and becomes the active project
in the selector at the top; the app moves you to the **Ingestion** tab, ready
for Step 2 (adding documents). The project has no documents yet, so the later
tabs (Correction Pipeline, Report & Export) stay disabled until Ingestion has
what it needs.
