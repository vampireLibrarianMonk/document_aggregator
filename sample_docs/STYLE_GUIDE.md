# Incident Aggregation Report — Style Guide (Gold Template)

This style guide is the template the pipeline fills. It is not something a model
guesses at. Section ordering and table layouts below are the target structure.

## Required Section Order

1. Executive Summary
2. Timeline of Events (ordered by effective date-time group)
3. Findings
4. Contributing Factors
5. Supplemental Input (comments, emails, interview notes)
6. Recommendations
7. Provenance and Sources

## Table Layout: Timeline

| Date | Site | Event | Source Document |
| ---- | ---- | ----- | --------------- |

## Rules

- Order all events chronologically by resolved effective date-time group.
- Every claim must trace back to a source document (filename + hash).
- Do not invent content. Words come from source documents.
- Supplemental input is attached as annotations, never merged into findings as
  if it were primary source content.
